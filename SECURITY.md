# Security policy

No executable or release exists. No version is currently supported as an installed product.

**Private vulnerability reporting is enabled**, verified through GitHub's API on 4 November 2026. Use [Report a vulnerability](https://github.com/AmanSikarwar/earkey-control/security/advisories/new) in the public repository's Security → Advisories section to contact the maintainer privately.

Do not post vulnerabilities, exploit payloads, access tokens, phone identifiers, or unrestricted diagnostics in a public issue. Share only the minimum sanitized reproduction through the private reporting form. No response-time promise is made.

The earlier HTTP 403 setup attempts remain recorded in the stage review; they do not describe the current reporting state. No test report was submitted during verification. See the [threat model](docs/threat-model.md) and [privacy requirements](docs/privacy.md).
