# Troubleshooting outline

No runtime exists yet. These are intended diagnostic outcomes, not implemented error codes or a tested command reference. Start with [recovery](recovery.md) if input or audio becomes unusable during a later authorized prototype.

| Future symptom | Safe response / evidence needed |
| --- | --- |
| Inactive after fresh install | Expected until measured enrollment and explicit activation; verify saved/active state separately |
| Unknown accessory / Unsupported | Leave untouched; collect bounded candidate/transport/mapping evidence with permission; do not widen identity rules |
| Ready or daemon running, no suppression | Check actual Active acknowledgment, effective backend and generation; reading events is not cancellation |
| Center toggle changes calls/assistant too | Review shared-signal group explanation; do not invent separate raw controls |
| Missing uinput / permission denial | Check actual service domain and object labels; remain inactive; no permissive/wildcard workaround |
| Competing remapper/grab | Report conflict, do not displace it or automatically switch backend |
| Held/stuck virtual key, duplicate allowed action | Pause; restore physical path, retain bounded evidence, investigate sequence/repeat/mapping; blocks stable release |
| Fault/restart latch | Keep inactive; inspect sanitized cause, recover only through explicit validated operation; no endless restart |
| Update/ROM change | Preserve pause/preferences; validate schema/mapping/environment again; downgrade support if evidence no longer applies |
| Manager disable seems delayed | Use immediate Pause now when available; verify exact manager lifecycle and reboot requirement; do not assume instant toggle behavior |

Do not install unrelated root frameworks, replace a kernel, alter shared key layouts or disable audio interfaces as troubleshooting shortcuts. Share a minimal reproduction and sanitized local report; security details go through the private route in SECURITY.md.
