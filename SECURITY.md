# Security policy

No executable or release exists. No version is currently supported as an installed product.

The public repository is [AmanSikarwar/earkey-control](https://github.com/AmanSikarwar/earkey-control). **Private vulnerability reporting is disabled**, verified through GitHub's API on 4 November 2026. Enabling it was rejected with HTTP 403 for the current token; no working private reporting route or contact address is claimed.

Do not post vulnerabilities, exploit payloads, access tokens, phone identifiers, or unrestricted diagnostics in a public issue. Until the maintainer enables and verifies a private channel, retain details locally and request a private route without disclosing the vulnerability. No response-time promise is made.

The maintainer can enable private vulnerability reporting in the repository's security settings or provide suitable repository-administration access for setup. Verify it is enabled before advertising a report form; the issue chooser links to this policy meanwhile. No runtime release is eligible before the security reporting setup is resolved. See the [threat model](docs/threat-model.md) and [privacy requirements](docs/privacy.md).
